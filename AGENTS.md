# agents-orchestrator

These rules apply only in this repository. The global rules are in `global/AGENTS.md`.

- Before you change a file, read `CONTRIBUTING.md`.
- Before you write code, scripts, or tests, read `standards/code-conventions.md`.
- Before you write documentation, prompts, skills, or commit messages, read `standards/writing-conventions.md` and `standards/glossary.md`.
- Write repository text in English, in ASD-STE100 (STE).
- Before you complete a change, run `make test`.
